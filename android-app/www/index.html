Notifications

Notifications are off for this app.
Print progress
An ongoing notification per printer while it prints or prepares: progress, time left, height, and Pause/Resume and Cancel if your role allows. Another when it finishes, with a webcam snapshot.
Keep watching in the background
Progress keeps updating after you leave the app. A check every 15 minutes (Android’s minimum; longer when the phone dozes) notices prints started elsewhere.
Start live progress from the background
Android only lets that 15-minute check start live progress when octo·modern isn’t battery-optimised. Otherwise it shows the progress as of the check.

Browser push doesn’t work inside the app; these notifications replace it here. If you prefer browser push, it keeps working in Chrome on this phone.

Home-screen widget

A printer’s state, progress, time left and webcam snapshot. Resize it for a bigger snapshot. You can also add it from the home screen: long-press, Widgets, octo·modern.
